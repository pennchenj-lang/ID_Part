## Reading and reuse

- CSV files contain per-case or summary quantities; JSON files record protocols, audits and provenance. [Shared code](shared_code/) includes the source snapshots used by these analyses.
- Original photographs, mask/image pools, model weights and runtime environments are excluded. These records support numerical review and statistical recomputation; full pixel-level replay needs the separately obtained licensed inputs, frozen implementation and dependencies.
- Public copies replace machine-specific path prefixes with __WORKSPACE__, __RUNTIME_ROOT__ and __USER_HOME__. Numerical values, identifiers, timestamps and embedded historical hashes are retained. Historical hashes refer to the original evidence; PUBLICATION_MANIFEST.json records original and public SHA256 values. Path-bearing scripts need root rebinding. Older completion records describe their original analysis state, not the final manuscript state.
- Correctness, choice-set size, root quality, segmentation quality and image reconstruction are separate endpoints. Read each protocol and denominator before comparing values across cohorts.

## Publication integrity and access

This directory contains 260 scientific source files plus publication metadata. [PUBLICATION_MANIFEST.json](PUBLICATION_MANIFEST.json) maps each original source SHA256 to its path-sanitized public SHA256; [FILE_MANIFEST.json](FILE_MANIFEST.json) lists the checksums of every published payload file. [original_source_manifest.json](original_source_manifest.json) retains the original source-file checksums. Only machine-specific path prefixes are replaced; experimental quantities and embedded historical evidence hashes are unchanged.

__WORKSPACE__ identifies the analysis workspace, __RUNTIME_ROOT__ the earlier inference runtime, and __USER_HOME__ the originating user environment. These tokens describe provenance locations and are not bundled inputs. Rebind paths and obtain the documented dependencies and licensed datasets before attempting archived scripts. This deposit supports source-table review; it is not a self-contained image/model execution environment.
